# Learning and credentials tied to a real gap

First determine whether the gap is **missing description**, **missing experience**, or **a stated credential requirement**. Improve the description before prescribing new training. A skill claim with no bullet example is not proof that the candidate needs a course.

## Recommendation method

For each useful recommendation state the actual gap, the role need it addresses, the least costly suitable action, expected artifact or capability, and any dependency. Use these labels: **Required qualification**, **Skill builder**, **Optional signal**, **Defer**. Use “required” only for an explicit applicable requirement; do not turn sector stereotypes into gates.

| Target | Practical evidence to develop if missing | Credential research, only if warranted |
|---|---|---|
| IT support / systems / network | Troubleshooting record, script, deployment or recovery exercise | Relevant infrastructure/vendor track or foundational certification |
| Cloud / platform / security | Small IaC control, identity/logging design, validation record, teardown plan | Current cloud-provider security/infrastructure pathway |
| SOC / detection / DFIR | Investigation narrative, tested rule, timeline, telemetry limitations | Analyst/response track aligned with target tools and budget |
| VM / exposure | Prioritization method, defined asset population, remediation and exception workflow | Training for the actual platforms and concepts; cert only if useful |
| AppSec / product | Threat model, code review, fixed issue and retest, pipeline design | Secure development or application-testing pathway |
| Offensive security | Authorized lab report, attack-path explanation, retest or defensive validation | Current practical testing track aligned with the job |
| IAM / PAM / IGA | Lifecycle automation, privilege model, access review or federation design | Actual identity-platform pathway |
| GRC / audit / risk | Control test, risk memo, evidence plan, vendor decision | Audit, management, or risk credential matching the mandate |
| Leadership | Decision memo, resource case, strategy, incident exercise, development of others | Role-required credential or targeted executive learning; avoid stacking |

These are alternatives, not a mandatory shopping list. Favor one or two justified actions. Do not recommend another foundational cert automatically to an experienced practitioner or assume a CISSP holder can never benefit from targeted technical learning.

## Credential wording

Preserve exact issuer title and actual status. Distinguish a completed course, exam pass, associate designation, earned certification, expired credential, and intended study. Do not append a credential to the candidate's name before it is awarded. An omitted expiry date is not evidence of expiration.

For ISC2, passing an exam without completing the certification requirements does not grant CISSP/CCSP certification. Use the designation actually awarded, such as **Associate of ISC2**; do not invent “Associate CISSP.” Check current issuer rules before advising on mark usage. [ISC2 Associate guidance](https://www.isc2.org/certifications/associate).

## Refresh before recommending

Verify current name, availability/retirement, prerequisites, exam versus certification status, renewal requirements, costs, and learning scope with the issuer when material. Do not hardcode costs, study durations, or hiring ROI. Give effort estimates only with assumptions about background and available time.

As checked 2026-09-07, Microsoft's retirement list gives **August 31, 2026** for Azure Security Engineer Associate. Do not prescribe that retired path as a new exam goal. Existing holders' credential validity is a separate question governed by issuer rules. [Microsoft credential retirement](https://learn.microsoft.com/en-us/credentials/support/credential-retirement). Legacy samples or JDs may still name retired credentials; preserve the quote and flag the dated requirement.

For DoD roles, verify the current DCWF role/proficiency and qualification options rather than assuming one cert qualifies every cyber job. See the federal reference. If research is unavailable, provide a role-linked learning objective and mark credential specifics unverified.
