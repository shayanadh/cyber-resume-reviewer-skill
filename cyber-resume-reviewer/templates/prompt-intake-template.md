# Optional intake

Use only for missing context that matters. Do useful work with supplied information before asking nonessential questions.

Suggested prompt for a candidate:

“Please review or rewrite the attached resume for [target title]. Here is the JD, if available. I want [quick feedback / exact edits / complete rewrite] in [format]. Additional facts you may use: [scope, actions, results, credential status].”

Minimum for wording improvements: resume content. A target and JD improve tailoring but are not prerequisites for general edits. If the resume itself is missing, ask for it. If facts are redacted, respect the redaction and distinguish review-copy omissions from real submission defects.

Ask about location, travel, work authorization, or clearance only if a target requirement makes the answer relevant. Do not request private explanations of career gaps or credentials merely to complete an intake form.
