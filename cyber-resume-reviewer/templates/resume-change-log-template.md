# Candidate change tracking

Use when comparing versions or explaining implemented edits. Distinguish proposed changes from applied changes and pending facts.

| ID | Section/location | Original | Revised/action | Source for any added fact | Why | Status |
|---|---|---|---|---|---|---|
| R1 | Role/bullet | Exact quote | Rewrite/move/merge/delete/retain | Resume/user source or none | Target-specific benefit | Applied / Proposed / Needs fact |

Keep chronology and source attribution when moving or merging content. Do not count the same moved bullet as a new achievement. Compare scores only when the target, rubric profile, and assessed categories stayed the same.
