# Complete rewrite

When requested, deliver the rewritten resume using established facts. Do not require another confirmation or attach a mandatory full scored report. Match the requested output format; use accessible plain text or Markdown if none is specified and file generation is unnecessary.

## Structure

Choose relevant sections and ordering:

- Candidate name and provided contact information.
- Target headline distinct from historical titles; optional concise evidence-based summary.
- Relevant skills in compact groups, placed where useful.
- Experience with employer, actual title, stated dates, and bullets. Keep promotions and concurrent/contract roles understandable.
- Education and credential entries using actual completion/status wording.
- Projects, community work, publications, speaking, or other proof when relevant. Clearly label lab/personal/advisory work.

Do not fill absent fields with invented facts. Do not add phone, location, LinkedIn, graduation year, clearance status, or a summary merely because the template has a slot. Employer-specific and federal requirements override optional structure.

## Writing and formatting

Preserve useful specificity, technical credibility, team attribution, and the candidate's voice. Use action, scope, artifact, method, and result as available, without forcing all elements into each bullet. Completed achievements use past tense even in the current role; ongoing responsibilities can use present tense. Keep punctuation and date presentation consistent without inventing month precision.

Use readable type, sensible spacing, and a clear reading order. Determine actual page count from the rendered document. Do not claim “ATS-safe,” guarantee a one-page result from text, or place review notes inside the resume body.

## Delivery status

If no unresolved placeholders remain, provide the clean resume and a short factual-review note if needed. Do not put “DO NOT SUBMIT” on every rewrite.

If the user requested a fill-in draft or essential fields are missing, label it **Draft with unresolved facts**. Use `[VERIFY: specific fact]` and list every occurrence outside the resume:

| Location | Exact placeholder | Fact needed | Essential or optional |
|---|---|---|---|
| Relevant role/bullet | Exact token | Specific question | Explain effect |

Prefer omitting an unsupported enhancement over constructing an invented achievement around blanks. Optional missing metrics should not block a usable supported rewrite.

For PDF/DOCX deliverables, render and inspect all pages and verify extracted text if tools are available. State material limitations honestly. Do not claim validation that was not performed.
