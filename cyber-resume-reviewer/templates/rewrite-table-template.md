# Exact edits

| Priority | Location | Original text (exact) | Replacement or action | Why | Additional fact needed |
|---|---|---|---|---|---|
| High / Medium / Optional | Role, section, bullet | Quote from source; label combinations | Known facts only, or move/delete/retain | Concrete benefit | None, or optional question |

Use Critical only for a confirmed blocker or known factual error. An add has no original quote: label it “Add from [source location/user statement].” Every new substantive claim must trace to that source. Retaining good wording is valid.

For optional expanded versions requiring missing facts, keep them separate from the ready-to-use edit and use `[VERIFY: precise fact]` only in a clearly incomplete fill-in draft. No inferred products, outcomes, ownership, or credentials inside a clean replacement.
